# Composer live-drive fixtures

These files are the fixed inputs for the Reframe composer attachment acceptance drive.

- `AXComposerFixture.png` — image attachment fixture.
- `AXComposerFixture.fountain` — file/source attachment fixture.

The live drive uses these concrete paths. It does not use Finder, Preview, clipboard paste, drag-and-drop,
filename search, or a temporary copy as an attachment source.
